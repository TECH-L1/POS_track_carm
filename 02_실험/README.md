# 실험 입력과 판정

## 입력

- 영상: `KakaoTalk_20260901_144821449.mp4` (1920×1080, 59.398 fps, 1206 프레임, 20.30 s)
  커팅매트 위 열화상 인쇄물 + 10 mm 체커보드 3장, 폰 카메라 하향 이동 촬영
- **REF(기준 궤적): 10 mm 체커보드 좌·상 보드** — 우측 보드는 제외
- 영역 폴리곤: `config/regions_f0.json` (f0 영상좌표계의 `LEFT` / `TOP` / `PRINT`)
- 렌즈 왜곡: `config/distortion.json` — 자가보정 결과 **무시 가능**(0.1% 개선)이라 보정 없이 진행
- 카메라 내부 파라미터·테이블 기준점 실측값은 **불필요**해졌다.
  체커보드 격자 자체가 미터 자(10 mm/칸) 역할을 하기 때문이다.

## 처리

`code/` 아래. 실행 순서와 산출물은 `03_결과/XY추정_v1/README.md` 참조.

1. `bootstrap.py` — 프레임간 강체 누적. 마스크 전파와 격자 인덱스 배정 예측에만 쓴다
2. `calibrate.py` — 체커보드 격자의 이상 정수격자 제약으로 렌즈 왜곡 자가보정
3. `ref_track.py` — **격자 앵커 REF**. 격자좌표→영상 호모그래피를 매 프레임 새로 적합해
   프레임간 누적 드리프트를 원천 제거한다 (체인 방식은 왕복 후 3~4 mm 드리프트가 남았다)
4. `validate_ref.py` — REF 자체 검증 V1~V6
5. `estimate_xy.py` — 피검 추정기. PRINT 영역만 마스킹 → KLT → 중앙값/MAD 이상점 제거 →
   공통 픽셀 이동량 (du,dv) → mm 변환 → 누적
6. `degrade.py` — 해상도·노이즈 열화 스윕
7. `report.py` — CSV·궤적 그래프·히트맵·검증 영상 생성

## 성공 판정

### 1차 관문 — REF 자체 검증 (`validate_ref.py`)

REF는 진값이 아니라 또 하나의 추정이다. 추정기와 비교하기 전에 **REF의 잡음 바닥이
비교 대상 오차보다 작다는 것**을 먼저 보여야 한다.

| ID | 검증 | 기준 | v1 결과 |
|---|---|---|---|
| V1 | 무이동 7.6 s 누적 드리프트 | < 0.5 mm | 0.0377 mm PASS |
| V2 | 약 200 mm 왕복 후 원점 재통과 잔차 | < 2.0 mm | 0.2277 mm PASS |
| V3 | 좌·상 보드 독립 측정 차이 (중앙값) | < 0.3 mm | 0.1120 mm PASS |
| V4 | mm/px 변동폭 (카메라 높이 변화 지표) | < 3 % | 2.57 % PASS |
| V5 | 정/역방향 증분 차이 최대 (저속 구간) | < 0.5 mm | 5.51 mm **FAIL** |
| V6 | 프레임간 최대 이동 (반 칸 미만이어야 배정 무모호) | < 5 mm | 4.865 mm PASS |

V1·V2·V3가 관문이다. V5는 격자 주기성에서 오는 1% 수준의 단발 글리치로, 미해결 한계다.

### 2차 — 추정기 판정

- 알려진 XY 이동 경로(=REF) 대비 추정 궤적을 비교한다
- 정지 구간에서 누적 드리프트와 프레임별 위치 흔들림을 기록한다
- 오차는 mm와 **이동거리 대비 %** 둘 다로 보고한다 (목업 축척이라 실물 외삽에 필요)
- 오차를 **추적 기여(oracle)** 와 **축척·방위 기여(fixed − oracle)** 로 분해한다
- 대조 실험: 같은 추정기를 체커보드 영역에 돌려, 성능 한계가 텍스처인지 누적인지 가른다

### 판정 시 반드시 같이 밝힐 것

- 첫 정지구간(f2–456)만 진짜 무이동이다. 이후 "정지"는 손 미끄러짐 1.3~2.3 mm를 포함한다
- REF 정밀도는 속도 의존적이다 (고속 7% 구간에서 모션블러로 격자잔차 0.48→0.84 px)
- 프레임 단위 증분 비교는 REF 잡음 419 µm에 막힌다
