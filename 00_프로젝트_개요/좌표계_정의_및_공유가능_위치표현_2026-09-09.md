# 수술대 기준 C-arm 위치 표현과 좌표계 정의

## 1. 연구 방향

> **C-arm이 수술대 기준으로 어디에 있는지, 공유 가능한 위치 표현으로 제공한다.**

2026-09-10 사용자 의견: “장비가 수술대 기준 어디에 있는가”가 가장 적합하다.
이를 1차 연구 방향으로 반영한다. 이전 문서의 해부학적 조사 위치 이해 / 동일 영상 재현이라는
양자택일 대신, 장비 위치 표시를 중심으로 목표를 정리한다.

초기 구현 범위는 **높이·방향 고정 조건에서 장비 기준점의 수술대 평면상 X·Y 위치**다.
완전한 6자유도 위치·자세 추정은 현재 검증 범위에 포함하지 않는다.

## 2. 무엇의 위치를 표시하는가

| 구분 | 이번 목표에서의 역할 |
|---|---|
| 수술대 | 위치를 표현할 기준 좌표계 |
| C-arm의 지정 기준점 | 최종적으로 위치를 표시할 대상. 기준점 선정은 미정 |
| 열화상 카메라 | 현재 XY 이동을 추정하는 센서 |
| X-ray 중심선과 조사영역 | 이후 확장 후보 |
| 환자와 해부학적 부위 | 이번 위치 출력의 기준으로 사용하지 않음 |

“장비 위치”가 본체, 검출기 중심, 또는 다른 고정점 중 무엇을 뜻하는지 정해야 한다.
카메라 위치를 그대로 장비 전체의 위치라고 부르지 않는다.

## 3. 좌표계와 출력 규약

- 수술대 좌표계: 테이블 상면의 지정 모서리를 원점으로 삼는다. 어느 모서리인지와 양의 방향은 실험 전에 기록한다.
- X: 수술대 장축, Y: 수술대 단축. 기존 실험 규약의 테이블 크기는 `1960 mm × 586 mm`다.
- 목표 출력: 지정한 장비 기준점의 `(X_mm, Y_mm)`.
- 보조 출력: 프레임 간 이동량 `(dX_mm, dY_mm)`과 추적 유효 여부.
- 높이와 방향: 초기 실험에서는 고정 조건으로 기록하며, 추정 결과로 표시하지 않는다.

표시 예시(설명용 가상 값):

> 수술대 원점 기준: 장축 742 mm, 단축 38 mm — 기준점: 사전에 지정한 장비 고정점

수술대 원점에 연결되지 않은 시작 프레임 대비 누적 이동량은 **시작점 대비 상대 이동**으로 표시한다.
이를 수술대 기준 위치로 보고하려면 초기 위치를 수술대 좌표로 정해야 한다.

## 4. 카메라 추정값을 장비 위치로 연결하는 조건

카메라와 선택한 장비 기준점의 상대 위치·방향을 정의하고 검증해야 한다.
높이·방향과 장착 관계가 고정된 XY 실험에서는 수술대 좌표로 표현한 두 점 사이 오프셋을 사용한다.
관절 움직임 등으로 그 관계가 바뀌는 기준점을 선택하면 하나의 고정 오프셋을 적용할 수 없다.

장비 위치 저장과 복귀는 이후 확장 후보로 둔다.
**장비의 수술대 기준 위치가 같다는 것만으로 동일한 환자 영상이 재현됐다고 판단하지 않는다.**
영상 재현은 환자 상태와 촬영 기하까지 별도로 검증해야 하는 목표다.

## 5. 현재 결과와 남은 검증

현재 결과는 인쇄물 목업에서 카메라의 평면 이동을 추정한 것이다.
총 이동 `773 mm`에서 최종 오차 `6.36 mm` (`0.82%`)를 얻었다.
이 수치를 수술대 기준 C-arm 위치 정확도로 바로 해석하지 않는다.

| 항목 | 현재 상태 / 다음 작업 |
|---|---|
| 장비 기준점 | 미정 — 표시할 물리적 점을 선정 |
| 수술대 원점·축 방향 | 모서리 기준 규약만 있음 — 실제 초기화 절차 정의 |
| 카메라와 장비 기준점 관계 | 미정 — 장착 위치와 고정 관계 확인·보정 |
| 높이·방향 고정 | 초기 실험 전제 — 고정 마운트로 유지 |
| 움직이는 대상과 카메라 이동 분리 | 미검증 — 정적 수술대 기준점과 움직이는 대상을 함께 촬영 |
| 실제 열화상 센서 검증 | 미수행 — 기존 결과는 인쇄물을 RGB 카메라로 촬영한 목업 |
| 목표 정확도와 드리프트 허용치 | 미정 — 용도에 맞게 정한 후 평가 |

다음 실험은 원점·장비 기준점·장착 관계를 기록하고, 수술대 기준 위치 오차와 정지 드리프트,
움직이는 대상이 있을 때의 추적 유효성을 평가하도록 구성한다.
