# 수술대 기준 C-arm 위치 추정

## 1차 목표

**C-arm이 수술대 기준으로 어디에 있는지 표시한다.** 2026-09-10 사용자 의견을 반영한 연구 방향이다.

첫 구현은 높이·방향 고정 조건에서 장비 기준점의 수술대 평면상 X, Y 위치를 목표로 한다.
이를 위한 현재 하위 과제는 열화상 영상에서 **카메라의 회전 없이 발생하는 테이블 평면상 X, Y 이동**을 추정하는 것이다.
카메라 추정값을 장비 위치로 표현하려면 장비 기준점 선정과 카메라 장착 관계의 정의·검증이 필요하다.
해부학적 조사 위치 식별과 동일 영상 재현은 1차 목표에 포함하지 않는다.

- 추정 대상: 카메라의 누적 위치 `(X_mm, Y_mm)` 및 프레임 간 이동량 `(dX_mm, dY_mm)`
- 제외 대상: 환자 위치/자세 추정, 방사선 조사영역 최적화, 선량 관리, 3차원 자세(roll/pitch/yaw) 추정
- 전제: 카메라 높이와 방향은 고정이며, 카메라는 테이블 평면과 평행하게 XY 방향으로만 이동한다.

## 좌표계

- 기준 평면: 일반 임상용 X-ray 테이블 상면 (`1960 mm × 586 mm`)
- `X`: 테이블 장축(1960 mm)
- `Y`: 테이블 단축(586 mm)
- 원점과 부호 방향은 실험 시작 전에 테이블의 한 모서리를 기준으로 고정한다.

## 방법

1. 테이블에 고정된 열화상 가시 기준점(마커 또는 테이블 모서리)을 영상에서 검출한다.
2. KLT로 **정적 기준점만** 프레임 간 추적한다.
3. RANSAC 또는 중앙값으로 이상점과 사람의 움직임을 제외하고 공통 픽셀 이동량 `(du, dv)`을 얻는다.
4. 보정된 mm/pixel 스케일 또는 평면 호모그래피로 `(du, dv)`를 `(dX_mm, dY_mm)`로 변환하고 누적한다.
5. 기준점이 부족하거나 추적 신뢰도가 낮으면 해당 프레임을 무효 처리하고 마커를 재검출한다.

## 필수 조건

- 영상마다 실제 위치를 아는 테이블 기준점 4개 이상이 보여야 한다.
- 기준점은 테이블에 고정돼 있어야 하며, 환자 신체의 특징점은 카메라 이동 추정에 사용하지 않는다.
- 절대 좌표는 첫 프레임의 기준점 검출로 초기화한다. KLT 누적만으로는 장기 드리프트를 제거할 수 없다.

## 현재 자료의 확인 결과

- `01_입력자료/열화상_영상/KakaoTalk_20260901_095945098.mp4`: 1920×1080, 약 59 fps, 4.26초
- 사람 윤곽/얼굴에서 KLT 특징점 추적 자체는 가능함.
- 다만 현재 영상에는 테이블의 정적 기준점이 뚜렷하지 않아, 이 영상만으로 카메라 XY 이동을 신뢰성 있게 분리할 수는 없음.
